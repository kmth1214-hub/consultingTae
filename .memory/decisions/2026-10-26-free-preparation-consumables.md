# 소모품을 발사 준비 행동으로 변경

- 사용자 동의: 소모품 사용 후 즉시 반격하지 않는다. 사탕 발사 후에만 반격하며, 발사 사이 소모품은1개만 사용한다.
- 불공은 다음 사탕 강화, 방어는 다음 발사 후 반격 차단, 회복은25 온전히 회복, 창은 기존 최대3명 피해를 유지한다.
- 소모품은 탄수·턴·적 순서·보스 공격 횟수를 진행시키지 않는다. 아이템 사용 횟수·연금술사 점수는 유지한다.
- 사용 제한은 엔진의 consumableUsedSinceShot:boolean으로 관리한다. 수락된 사탕 발사/새 라운드에서만 해제하며 취소·재조준·실패한 입력은 해제하지 않는다.
- 기존 빈 아이템/동결/조준/반격/결과 확인 중 금지는 유지한다. 창으로 전멸 시 반격 없이 기존 클리어·보상 흐름을 따른다.
- 기존 적 모션 테스트는 소모품이 아닌 실제 사탕 발사로 반격을 유발하도록 수정한다.
