# Decision: Snow candy reward unlock

- 확정: 기본 쿠키/사탕 3종(모험가·연금술사·마법사)은 유지한다. 우유맛·바람궁수 사탕만 눈 지역 클리어 전 보상에서 제외한다.
- 라운드 선택 보상과 야영지 무작위 보상 모두 같은 제한을 사용한다. 등급/합성/소모품 확률은 유지한다.
- 기존 브라우저 프로필 해금 또는 현재 플레이의 눈 보스 클리어가 있으면 두 사탕을 보상 후보에 포함한다. 눈 보스 클리어 직후 보상부터 적용한다.
- 현재 플레이 달성 기록 `snowAreaCleared`와 이전 프로필 해금은 분리한다. 이전 해금 때문에 새 플레이가 눈을 클리어한 것으로 기록되면 안 된다.
- 관리자 테스트는 기존 격리된 해금 프로필을 사용한다. 실제 사용자 프로필에는 쓰지 않는다.
