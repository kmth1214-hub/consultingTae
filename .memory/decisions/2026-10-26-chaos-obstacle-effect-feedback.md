# 혼돈 물체 효과 표시 누락

- 재현: `node tmp/chaos-obstacle-repro.cjs`. 혼돈1/seed4927/단일 얼음(32.5도,power.6)/RNG.25에서 실제 ice-guard와 피해감소.5는 적용되지만 frostVisible=false. 동일 무작위 방어를 통나무로 발동해도 같았다.
- 원인: BattleArena의 한기·폭발 렌더링은 snow/city 지역 조건뿐이고, 혼돈의 엔진 결과 obstacleEffects와 연결되지 않았다. 단일 접촉에서도 재현되어 연쇄/중복 처리 원인은 제외했다.
- 혼돈은 재질과 무관하게 단일피해3/다음 공격50%감소/전체1~2피해/다음한발반전 중 동일확률 선택하는 기존 규칙 유지.
- 무작위 결과는 전투 엔진이 확정한 후 표시한다. 미리보기나 장식에서 RNG를 다시 뽑지 않는다. 발사 결과 확인2초 동안 실제 효과의 한기/폭발/타격/반전 표시와 짧은 설명을 제공한다.
- 눈/도시의 기존 접촉 즉시 연출은 유지한다. 이전 라운드·소모품 이벤트와 중복 대상의 재생을 막는다.
