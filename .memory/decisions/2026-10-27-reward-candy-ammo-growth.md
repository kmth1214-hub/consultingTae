# 보상 사탕에 따른 라운드 탄약 증가 결정

- 요청: 보상으로 마법사탕을 추가로 얻어도 매 라운드 발사 횟수가 9회로 고정되는 문제를 수정한다.
- 시작 사탕 1개일 때 한 라운드 기본 발사 횟수는 9회다.
- 사탕을 합성하지 않고 별도 사탕 1개를 보유할 때마다 **다음 라운드부터** 발사 횟수를 1회 늘린다. 즉 라운드 시작 시 `maxAmmo = 9 + max(0, weapons.length - 1)`, `ammo = maxAmmo`다. 테스트용 빈 사탕 목록도 최소 9발로 유지한다.
- 같은 사탕을 합성해 등급을 올리면 보유 사탕 개수가 그대로이므로 발사 횟수는 늘지 않는다.
- 라운드 보상 화면에서 받은 직후 현재 라운드의 남은 발사 횟수는 바꾸지 않는다. 야영지 보상과 혼돈 지역 진입도 새 라운드 시작 규칙을 따른다.
- 보유 사탕은 기존처럼 장전 순서를 구성하며, 라운드당 사탕 종류별 발사 횟수를 별도로 정하지 않는다. UI의 총 탄약·탄약 점·홈 설명은 실제 규칙과 일치시킨다.
- 사용자 선택: “새 사탕 1개마다 다음 라운드부터 +1발, 합성은 증가 없음”.
