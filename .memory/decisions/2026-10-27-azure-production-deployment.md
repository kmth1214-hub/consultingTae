# Azure 실배포 연결 결정

- Date: 2026-10-27
- 사용자가 스토리지 계정, `LeaderboardRecords` 테이블, Standard Static Web App, Entra 앱 등록을 생성했고 나머지 설정과 배포를 위임했다.
- 리소스 그룹: `grill-me-edu`. 기존 게임·API·회사 단일 테넌트 인증 설계를 유지한다.
- `origin/main`에는 Azure 포털이 생성한 별도 배포 workflow 한 개가 추가되어 있다. 로컬의 최신 게임 커밋과 원격 이력을 보존해 병합하고, 검증·테넌트 설정·API 배포가 포함된 기존 workflow 하나로 통합한다.
- 비밀은 Azure 환경 변수와 GitHub Actions Secrets에만 저장한다. 키를 재발급하거나 무관한 리소스·접근 권한을 변경하지 않는다.
- Azure 로그인과 MFA는 사용자가 직접 처리하며, 나머지 설정·코드 반영·검증은 위임 범위에서 진행한다.
- 실제 배포가 성공하고 인증 및 리더보드 동작을 확인한 뒤 완료로 기록한다. 접근 불가 또는 확인하지 못한 항목을 완료로 표시하지 않는다.
