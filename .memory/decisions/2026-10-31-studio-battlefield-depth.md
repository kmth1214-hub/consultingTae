# Decision: 관리자 전투 화면의 2.5D 입체감

## 목표

넓은 전장이 평면으로 보이는 문제를 로컬 관리자 테스트 플레이에서 먼저 개선한다. 원본 지역 일러스트의 풍경과 조준 가독성을 유지하면서 길의 두께, 물체의 접지, 높낮이 차이를 드러낸다.

## 사용자 결정

- 표현 방식: 기존 일러스트 기반 2.5D. 길의 윗면·측면·그림자와 오브젝트 높낮이, 기존 시차를 강조한다.
- 대상 지역: 숲·눈·도시·혼돈 모두 같은 깊이 기준으로 비교한다.
- 적용 화면: `/__dev/maps`의 **테스트 플레이만**. 지도 미리보기와 일반 사용자 게임은 변경하지 않는다.

## 코드에서 확인한 제약과 구현 방향

- `BattlefieldBackdrop`은 이미 하늘·원경·중경·길·전경 5개 층과 카메라 시차를 제공한다. 배경 파일을 교체하거나 카메라 계산을 변경하지 않는다.
- 전투 월드는 3600×1200, 지면은 `groundY=900`이다. 길과 전경 그림이 겹치므로 불투명한 큰 면으로 원경·중경을 가리지 않는다.
- `ArenaScenery`, `MonsterGroup`, `PlayerCookie`, `Slingshot`의 위치와 충돌은 `buildPlayableBattlefield`의 월드 좌표를 따른다. 입체감은 장식 전용 SVG/CSS로 구현하고 `pointer-events: none`, `aria-hidden`을 적용한다.
- 관리자 세션의 `run`에 명시적 시각 플래그를 둬 `BattleArena`에서만 입체 장식을 렌더링한다. 일반 세션에 플래그가 없으면 기존 화면을 그대로 렌더링한다.
- 지역별 색은 기존 `getSceneProfile` 팔레트를 기준으로 정한다. 길의 가장자리·측면과 캐릭터·발사대·장애물 아래 그림자를 함께 맞춘다.
- 장식은 움직이는 사탕, 조준선, 몬스터, HUD보다 뒤에 두며 도시 원경을 덮지 않는다. `prefers-reduced-motion`에서도 정적인 깊이 표현은 남긴다.

## 검토 기준

- 관리자 테스트 플레이에서 네 지역 모두 길의 윗면과 측면, 접지 그림자가 보인다.
- 고지대 적·발사대와 바닥 물체의 높이 차이를 구분할 수 있다.
- 같은 관리자 화면의 지도 미리보기, 일반 게임, 물리·조준 결과는 이전과 같다.
- 로컬 링크 `/__dev/maps`에서 바로 확인할 수 있다. Azure 배포는 이번 검토 범위에 포함하지 않는다.
