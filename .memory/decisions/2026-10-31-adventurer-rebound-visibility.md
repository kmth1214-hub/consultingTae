# Decisions: 모험가 튕김 및 능력 연출 가시성

- Date: 2026-10-31
- Status: Confirmed

## D01. 모험가 전용 스톤의 튕김
- **Chosen**: 몬스터 직접 명중이나 바닥 착지 이후에도 튕긴다. C/B/A 등급별 최대 튕김 횟수는 1/2/3회다. 실제로 닿은 각 몬스터에게 등급별 무작위 피해를 독립적으로 추첨하며 같은 몬스터를 한 발로 중복 타격하지 않는다.
- **Rationale**: 사용자가 충돌과 반동을 보고 다음 몬스터를 노릴 수 있게 한다. 최신 요청인 명중별 별도 추첨을 적용한다.

## D02. 시각 효과
- **Chosen**: 튕김마다 눈에 띄는 반동 효과를 표시하고 연금술사 폭발은 기존 성공률·피해·범위를 유지하면서 시각 효과를 강화한다.
- **Rationale**: 현재 짧은 먼지와 얇은 원형 파동은 플레이 중 알아보기 어렵다.

## D03. 지도 입체감 확인
- **Chosen**: 로컬 관리자 테스트 플레이에 원본과 2.5D 장면을 전환하는 비교 버튼을 둔다. 지도 미리보기와 일반 게임은 기존 범위를 유지한다.
- **Rationale**: 앞선 관리자 시범판 결정의 적용 위치를 명확히 보여준다.
