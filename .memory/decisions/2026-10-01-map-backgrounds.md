# Decisions: Map Background Artwork

- Date: 2026-10-01
- Status: Confirmed

## D01. Background artwork source
- **Chosen**: Use the four custom theme images in `Cookie Run_ OvenBreak Fan Kit/4_theme_maps/`: `forest_theme.png`, `snow_theme.png`, `city_theme.png`, and `chaos_theme.png`.
- **Rationale**: These are the map-specific images the user identified and they are composed as wide landscape scenes, so they fit the battle arena better than the portrait Land cards.

## D02. Area-to-image mapping
- **Chosen**: Forest uses `forest_theme.png`, Snow uses `snow_theme.png`, City uses `city_theme.png`, and the bonus Chaos area uses `chaos_theme.png`.
- **Rationale**: Each illustration is labeled for its matching area and the Chaos illustration is already provided separately.

## D03. Placement
- **Chosen**: Use the selected image as the background of the in-game battle arena, keeping the combat elements and HUD in the foreground.
- **Rationale**: The map should establish the current area while keeping the playable combat scene legible.
