# Decisions: 선택 쿠키 12명과 전용 스톤 7종

- Date: 2026-11-26
- Status: Confirmed
- Scope: 설계 결정. 이 문서에서는 구현·배포를 하지 않는다.

## D01. 추가 명단과 해금

- **Chosen by user**: 기존 모험가맛·연금술사맛·마법사맛·우유맛·바람궁수 5명을 유지하고, 용감한 쿠키·딸기맛·체리맛·칠리맛·에스프레소맛·바다요정·서리여왕 7명을 추가해 총 12명으로 만든다.
- **Chosen by user**: 새 7명 중 바다요정과 서리여왕만 눈 지역 클리어 후 해금한다. 나머지 5명은 처음부터 선택 가능하다. 기존 우유맛·바람궁수의 눈 클리어 해금도 유지한다.
- **Code-derived**: 해금은 `snowAreaCleared` 계정 프로필의 기존 불리언을 재사용한다. 새 DB 필드나 테이블은 필요하지 않다. 잠금 캐릭터와 스톤 카탈로그에 같은 `requiresSnowClear` 기준을 적용한다.
- **Rationale**: 사용자가 정한 명단·진행 보상을 유지하면서 현재 계정별 해금 저장 방식을 재사용한다.

## D02. 그림 자산

- **Chosen by user**: 로컬 팬키트의 `GingerBrave.png`, `Strawberry Cookie.png`를 새 두 캐릭터에 사용한다. 체리맛·칠리맛·에스프레소맛·바다요정·서리여왕은 현재 게임의 동화풍 표현에 맞춘 새 일러스트 5장을 제작한다.
- **Implementation judgment**: 새 그림은 캐릭터별로 투명 배경 PNG로 만들고, 캐릭터 선택 카드와 새총 옆 플레이어 표현에 같은 자산을 사용한다. 외부 게임 스크린샷·UI를 자산으로 복제하지 않는다. 12장 카드가 데스크톱·좁은 화면에서 스크롤·선택 가능하도록 레이아웃을 조정한다.
- **Code-derived**: `src/game/assetCatalog.js`에는 기존 5명만 import되어 있고, `src/components/CharacterSelect.jsx`는 `CHARACTERS` 목록을 그대로 그린다.

## D03. 전용 스톤 공통 계약

- **Chosen by user**: 새 7명에게 각각 전용 스톤 1종과 그에 맞는 특수효과를 준다. 체리맛·에스프레소맛 두 스톤은 비행 중 추가 클릭 또는 Space로 타이밍을 정한다. 나머지 5종은 조건에 따라 자동 발동한다.
- **Implementation judgment**: 선택한 쿠키는 해당 C등급 전용 스톤 1개와 기본 스톤 2개로 시작한다. 슬롯 당첨 시 현재 해금된 12명 중 전용 스톤이 같은 확률로 나올 수 있고, 실패 보상은 기본 스톤 1개다. 다른 쿠키가 보상으로 받은 전용 스톤도 그 스톤의 능력을 사용할 수 있다. 기존 자동 합성·등급별 기본 피해·점수 계산·발사 횟수 규칙은 유지한다.
- **Implementation judgment**: 불공은 큰 스톤의 직접 피해만 2배로 만든다. 추가 효과의 고정 피해에는 적용하지 않는다. 창은 한 발의 전용 스톤 능력을 대체하며 기존 최대 3명 실제 관통 판정을 따른다. 스톤과 소모품은 발사·능력 발동 한 번당 하나씩만 소비한다.
- **Implementation judgment**: 새 스톤의 추가 피해는 해당 파편·베기·폭탄·파도가 실제 적의 충돌 영역과 만났을 때만 적용한다. 한 효과에서 같은 적에게 중복 추가 피해는 주지 않는다. 시뮬레이션·애니메이션·엔진 결과가 하나의 예약 발사를 공유하고 임의의 대상 ID로 피해를 만들 수 없게 한다.
- **Rationale**: 기존 5종과 같은 획득·등급·판정 체계에서 새 능력을 비교할 수 있다.

## D04. 자동 발동 스톤 5종

아래 기술·수치는 사용자의 "이후에는 추천안으로 추가" 지시에 따라 확정한 **새총 전투용 제안 규칙**이다. 원작 게임의 수치를 복제한 것이 아니다.

| 쿠키 / 스톤 | 발동·효과 | C / B / A 차이 |
| --- | --- | --- |
| 용감한 쿠키 / 용감한 돌진 스톤 | 발사 0.25초 뒤 수평 속도만 증가한다. 이후 실제 가속 궤적으로 충돌을 계산한다. 추가 피해는 없다. | 수평 속도 +12% / +18% / +24% |
| 딸기맛 / 회전 롤리팝 스톤 | 회전하는 큰 스톤으로 날아가며, 커진 실제 반지름으로 적·장애물·바닥 접촉을 판정한다. 기존 등급 피해만 준다. | 기본 스톤 반지름의 1.25 / 1.35 / 1.45배 |
| 칠리맛 / 칠리 베기 스톤 | 처음 직접 맞힌 적의 뒤쪽으로 짧은 베기가 나간다. 베기 선분에 실제로 닿은 **다른 적 1명**에게 고정 피해 1. 장애물이 가로막으면 멈추고 첫 대상은 다시 때리지 않는다. | 베기 최대 거리 180 / 240 / 300 월드 단위 |
| 바다요정 / 파도 스톤 | 첫 적·장애물·바닥 접촉점의 지면에서 발사 방향으로 낮은 물결이 전진한다. 지면에 닿아 있는 적 최대 2명에게 실제 접촉 시 고정 피해 1. 높은 받침 위 적과 공중 까마귀는 제외하고 장애물에 막힌다. | 물결 최대 거리 420 / 560 / 700 월드 단위 |
| 서리여왕 / 서리 스톤 | 적을 직접 맞히면 그 적과 가까운 적을 얼린다. 얼어붙은 적이 다음 반격자로 선택될 때 공격 1회를 건너뛰고 풀린다. 라운드 종료 시 해제, 같은 적에게 중첩하지 않는다. 보스도 한 번만 건너뛴다. | 직접 맞힌 적 1명 / 그 적+반경 180 내 가장 가까운 적 1명 / 그 적+반경 240 내 가장 가까운 적 2명 |

- **Implementation judgment**: 가속·큰 반지름·베기·물결·빙결 모두 빗나간 샷에는 조건에 맞는 경우만 작동한다. 범위 피해와 얼림은 타격점·시간·실제 생존 적 위치를 사용한다. 점수는 실제 제거한 HP만 기존 등급 배율로 계산한다. 서리 스톤은 추가 피해가 없으므로 얼림 자체는 점수를 주지 않는다.

## D05. 타이밍 입력 스톤 2종

| 쿠키 / 스톤 | 발동·효과 | C / B / A 차이 |
| --- | --- | --- |
| 체리맛 / 체리 폭탄 스톤 | 비행 중 클릭·Space를 누르면 그 지점에 폭탄 1개를 떼어내고 원래 스톤은 계속 날아간다. 폭탄은 0.35초 뒤 현재 위치에서 폭발한다. 실제 폭발 반경에 든 가장 가까운 생존 적 최대 2명에게 각각 고정 피해 1. 수동 입력 전에 적·장애물에 닿으면 접촉점에 폭탄을 자동 설치한다. 바닥 착지 뒤에는 0.5초 입력 시간을 주고 자동 설치한다. | 폭발 반경 150 / 180 / 210 월드 단위 |
| 에스프레소맛 / 소용돌이 스톤 | 비행 중 클릭·Space를 누르면 현재 스톤 위치에 0.7초 소용돌이를 만든다. 반경 내 일반 적을 중심 쪽으로 실제로 당겨 빈 위치에 옮긴다. 보스는 이동하지 않는다. 당김 자체에는 피해가 없고 이후 스톤·장애물과의 실제 충돌만 피해를 준다. 직접 입력 전에 적·장애물에 닿으면 그 접촉점에서 자동 발동한다. 바닥 착지 뒤에는 0.5초 입력 시간을 준다. | 반경 170 / 210 / 250, 최대 이동 60 / 80 / 100 월드 단위, 최대 대상 2 / 2 / 3명 |

- **Implementation judgment**: 에스프레소 이동은 월드 밖·장애물 안·다른 적과 겹치는 위치에 둘 수 없다. 바닥 적은 지면을 유지하고, 공중 적의 순찰 중심도 함께 이동한다. 받침 위 적이 받침 밖으로 이동하면 기존 낙하 규칙을 사용한다. 이동한 위치는 해당 라운드에 남고, 발사 결과와 다음 조준·미니맵에 반영한다.
- **Implementation judgment**: 능력은 한 발당 한 번만 발동한다. 타이밍 입력을 하지 않아도 첫 적·장애물 접촉이나 바닥 착지 후 자동 발동하여 무효 스톤이 되지 않게 한다. 모바일에서는 동일한 능력 버튼을 제공한다.
- **Rationale**: 체리 폭탄은 원래 스톤이 계속 비행하고, 에스프레소는 적 위치를 바꾸므로 연금술사의 즉시 확률 폭발·마법사의 분열과 구별된다.

## D06. 화면·호환·검증 범위

- **Implementation judgment**: 캐릭터 카드에 12명 이름·잠금 조건·짧은 능력 설명을 표시한다. 전투 HUD에는 현재 스톤의 명칭·등급·기본 피해 범위·능력 발동 방법·자동 발동 조건을 표시한다. 스톤마다 구분되는 외형과 발사·명중·능력 이펙트를 만든다. 빙결/소용돌이로 상태가 바뀐 적은 화면과 미니맵이 같은 위치를 사용한다.
- **Code-derived**: `src/game/gameData.js`, `src/game/assetCatalog.js`, `assets/js/battle-engine.js`, `src/game/shotGeometry.js`, `src/game/shotResolution.js`, `src/game/gameSession.js`, `src/components/BattleArena.jsx`, `src/components/CandyProjectileArt.jsx`, `src/components/CharacterSelect.jsx`, `src/game/candyPresentation.js`에 확장 지점이 있다. 리더보드는 쿠키 이름을 `CHARACTERS`에서 찾으므로 새 ID를 목록에 추가하면 표시할 수 있다.
- **Implementation judgment**: 기존 5명·바람 Q·마법사/연금술사 능력·장애물 연쇄·라운드/슬롯/해금 기록을 회귀 검증한다. 개발 중에는 변경 범위 국소 테스트·빌드만 수행하고, 사용자 지시대로 전체 테스트는 배포 단계에서 실행한다. 계획·구현 이후 사용자 화면에 바로 적용하는 방향으로 준비하되, 이 인터뷰만으로 Azure 배포를 실행하지 않는다.
