# Decisions: Chaos Fused Boss

- Date: 2026-10-26
- Status: Confirmed
- Feature: `chaos-fused-boss`
- Stage: 설계 인터뷰 완료. 구현은 후속 memory-plan / memory-execute에서 진행한다.

## D01. 혼돈 최종전의 구성
- **Chosen**: 혼돈 3라운드는 멧돼지·눈사람·화덕 로봇의 특징을 하나로 융합한 보스로 시작한다. 체력이 최대 체력의 50% 이하가 되면 세 보스로 분리한다. 분리는 전투당 한 번만 일어난다.
- **Rationale**: 기존 세 보스가 동시에 등장하는 최종전에 융합전과 분리전의 구분을 만든다.
- **Source**: 사용자 선택. 다른 지역과 혼돈 1·2라운드는 이번 변경 범위 밖이다.

## D02. 크기와 외형
- **Chosen**: 융합체는 일반 몬스터 기준 4.5배, 분리된 보스는 각각 3배다. 기존 기준 크기 92를 사용하면 각각 414 / 276 world units다. 융합체는 세 보스의 특징이 결합된 하나의 캐릭터로 표현한다.
- **Rationale**: 최종 보스의 위압감과 분리 후 각 보스의 정체성을 함께 유지한다.
- **Source**: 배율은 사용자 선택, 기준 크기와 실제 크기 환산은 기존 코드에서 확인.
- **Constraint**: 그림뿐 아니라 피격 범위·공격 시작점·카메라 구도·배치 간격을 동일한 크기 기준으로 맞춘다. 특히 작은 화면에서 보스가 HUD에 가려지지 않아야 한다.

## D03. 융합체의 공격 순서
- **Chosen**: 한 턴에 한 번 공격한다. 일반 공격은 세 보스의 공격을 순환하고 매 세 번째 공격은 특수기로 대체한다. 특수기는 돌진·얼음 숨결·화덕 과열 중 하나를 같은 확률로 독립 추첨한다. 같은 특수기가 세 번 연속 나와도 허용한다.
- **Rationale**: 기존 공격 리듬을 유지하면서 특수기의 예측 가능성을 낮춘다.
- **Source**: 사용자 선택.
- **Constraint**: 일반 공격의 순환 순서는 특수기 순서와 별도로 관리한다. 예: 멧돼지 일반 → 눈사람 일반 → 무작위 특수 → 로봇 일반. 단순히 전체 공격 횟수를 3으로 나누면 특정 일반 공격이 항상 특수기로 대체되는 문제가 생긴다.
- **Existing rules**: 공격 피해·각 특수기의 부가 효과·일반 투척의 실수 규칙은 기존 해당 공격을 재사용한다. 분리 후에는 각 보스의 기존 공격 순서와 개별 세 번째 공격 특수기를 사용한다.

## D04. 체력 보존과 분배
- **Chosen**: 분리 시점의 남은 체력을 기존 혼돈 세 보스의 체력 비율로 분배하며 합계를 보존한다. 분리 자체로 회복하지 않는다.
- **Rationale**: 융합체에 입힌 피해가 사라지거나 두 번째 체력 바가 추가되는 느낌을 피한다.
- **Source**: 비율 분배와 합계 보존은 사용자 선택. 기존 시작 체력은 코드상 15 / 18 / 23이며 합계는 56이다. 별도 체력 상향 요청이 없으므로 융합체의 시작·최대 체력 기준은 56으로 잡는다.
- **Constraint**: 정수 배분은 비율별 몫을 내림한 뒤 소수 부분이 큰 순서로 잔여 체력을 배분해 총합을 정확히 보존한다. 남은 체력이 아주 적어 몫이 0인 개체에는 체력을 새로 만들어 주지 않으며 기존 `hp <= 0` 처치 규칙을 적용한다. 분리 후 회복 가능 최대치는 기존 개별 보스 규칙을 따른다.

## D05. 분리 판정 시점과 처치 우선
- **Chosen**: 해당 발사의 직접 피해·관통·장애물 연쇄 효과를 모두 반영한 뒤 분리를 판단한다. 최종 남은 체력이 0이면 분리·착지 피해 없이 즉시 승리한다. 살아 있고 체력이 50% 이하일 때만 분리한다.
- **Rationale**: 이미 처치한 보스가 분리해 되살아나거나 처치 뒤 플레이어에게 피해를 주는 상황을 막는다.
- **Source**: 사용자 선택.
- **Constraint**: 분리로 새로 생성한 장애물이 분리를 유발한 발사의 과거 충돌을 다시 처리해서는 안 된다. 체력 판정과 분리 결과는 한 번만 확정한다.

## D06. 분리와 착지 연출
- **Chosen**: 융합체에서 나온 세 보스가 포물선을 그리며 서로 다른 위치에 떨어진다. 착지 충격과 함께 장애물이 다시 생성된다.
- **Rationale**: 전투 구성이 바뀌는 원인을 시각적으로 보여주고 다음 공략 기회를 만든다.
- **Source**: 사용자 요청.
- **Constraint**: 같은 라운드 안의 전환이므로 사탕·아이템·점수를 초기화하거나 보충하지 않는다. 라운드당 능력의 사용 기록도 유지한다. 전환 중 조준·아이템 입력을 막고 세 보스의 이동과 착지가 보이는 카메라 구도를 사용한다.

## D07. 장애물 교체
- **Chosen**: 기존 장애물과 잔해를 정리하고 새 장애물 3개를 생성한다. 각 보스의 착지 부근에 하나씩 놓으며 보스와 겹치지 않는다.
- **Rationale**: 흩어진 잔해와 새 물체가 겹쳐 판정이 복잡해지는 문제를 줄인다.
- **Source**: 사용자 선택.
- **Constraint**: 기존 무작위 배치의 접근 가능성·비중첩 검증을 재사용한다. 새 물체의 식별자와 배치는 이전 물체의 파괴·연쇄 이력을 물려받지 않는다. 혼돈 장애물의 기존 무작위 효과는 유지한다.

## D08. 착지 피해와 방어
- **Chosen**: 분리 턴의 일반 반격을 생략한다. 세 보스 착지 전체에 대해 플레이어에게 1~3 무작위 피해를 한 번만 적용한다. 방어 아이템과 우유 보호막은 차단하고 얼음 보호는 피해를 50% 감소시킨다.
- **Rationale**: 분리의 충격을 전투 규칙으로 표현하면서 세 번 연속 피격되는 부담은 피한다.
- **Source**: 사용자 선택.
- **Constraint**: 기존 방어 우선순위와 정수 피해 처리 규칙을 재사용한다. 착지 연출의 개별 프레임이나 각 보스의 착지 콜백에서 피해를 중복 적용하지 않는다. 착지 피해가 치명적이면 피격 결과를 보여준 뒤 패배 화면으로 이동한다.

## D09. 기존 전투 구조와 검증 범위
- **Chosen**: 전투 엔진에서 무작위 결과와 피해를 한 번 확정하고 화면은 그 결과를 재생하는 현재 구조를 유지한다. 일반 플레이와 개발용 관리자 플레이 모두 같은 전투·배치 로직을 사용한다.
- **Rationale**: 화면 재렌더링·탭 전환·연출 완료 콜백으로 특수기나 피해가 다시 추첨되지 않아야 한다.
- **Source**: 코드에서 확인한 기존 구조를 따른다.
- **Implementation references**: `assets/js/battle-engine.js`의 `createRoundEnemies`, `resolveEnemyTurn`, `finishAction`; `src/game/gameSession.js`의 `routeCombat`, `finishCombatRouting`; `src/game/battlefieldModel.js`, `src/game/battlefieldPlacement.js`, `src/game/battlefieldCamera.js`; `src/components/MonsterGroup.jsx` 및 공격·장애물 연출; `src/dev/createStudioSession.js`.
- **Required verification**: 50% 경계와 한 번만 분리, 직접 피해와 연쇄 피해 후 처치 우선, 정확한 체력 합계, 반복 특수기 허용과 일반 공격 순환, 장애물 교체·비중첩, 방어별 착지 피해와 치명타, 연출 중 입력 제한, 작은 화면 및 관리자 플레이에서 재현을 검증한다.

## Scope notes
- 사탕 1인칭 조작 보스 기믹, 지역 날씨·혼돈 궤도 뒤틀림, Azure 배포는 이번 기능에 포함하지 않는다.
- 기존 화덕 보스에는 시작 체력보다 높은 회복 상한이 있다. 융합체의 최초 체력과 분리 시 분배 비율은 현재 체력 합계 56을 기준으로 삼고, 분리 후에는 기존 개별 최대 체력 규칙을 유지한다.
- 기존 검증 완료 작업의 커밋은 앞서 발생한 자동 승인 검토 제한으로 대기 중이다. 이 문서는 실행 포인터를 변경하거나 해당 커밋을 대신 완료하지 않는다.
