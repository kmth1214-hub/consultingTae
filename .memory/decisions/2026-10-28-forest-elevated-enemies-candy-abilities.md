# Decisions: Forest Elevated Enemies and Candy Abilities

- Date: 2026-10-28
- Status: Confirmed
- Feature: `forest-elevated-enemies-candy-abilities`
- Scope: 로컬 관리자 지도 스튜디오의 숲 시범판. 사용자 게임과 Azure 배포에는 검토 후 별도 반영.

## D01. 숲 시범판과 공개 순서

- **Chosen by user**: 숲부터 완성해 로컬 `/__dev/maps` 관리자 화면에서 검토한다. 눈·도시·혼돈 확장과 사용자 화면 반영은 숲 시범판의 설정과 검토가 끝난 뒤 진행한다.
- **Rationale**: 높이 배치와 움직이는 적의 충돌 판정은 기존 전투 물리 규칙을 크게 바꾼다. 현재 관리자 화면은 개발 서버 전용이고 Azure에서는 차단된다.
- **Boundary**: 시범판의 새 배치·피해·사탕 효과는 관리자 테스트 전투에만 적용한다. 기존 사용자 게임, 리더보드, Azure 배포 결과를 바꾸지 않는다. 이후 사용자 반영은 별도 작업으로 다룬다.

## D02. 라운드와 적 배치

- **Chosen by user**: 숲 1라운드는 일반 몬스터와 쿠키·새총을 모두 바닥에 둔다. 2라운드는 일반 몬스터 1마리를 쓰러질 수 있는 통나무 더미 위에 반드시 올리고, 다른 적은 바닥에 둔다. 3라운드 보스는 바닥에 둔다.
- **Rationale**: 첫 라운드에서 조준을 익히고 둘째 라운드에서 높이와 낙하를 경험한다. 보스는 기존 장애물보다 커서 안전한 받침이 없다.
- **Existing rule**: 숲 일반전은 각각 1마리와 2마리, 3라운드는 보스다. 같은 라운드 배치는 시드로 고정하고 새 배치를 요청할 때만 바꾼다.

## D03. 발사대와 쿠키의 높이

- **Chosen by user**: 1라운드는 바닥에 고정한다. 2라운드부터 라운드 시작 때 바닥 또는 낮은 발판을 무작위로 정하고, 쿠키와 새총을 함께 이동시킨 뒤 라운드 동안 고정한다. 발사대 발판은 무너지지 않는 지형이다.
- **Rationale**: 시작점 높이가 바뀌면 조준·파워 선택이 달라지되 전투 중 좌표가 갑자기 흔들리지 않는다.
- **Implementation constraint inferred from code**: 현재 발사대와 쿠키 좌표뿐 아니라 조준 도달성 탐색, 투사체 시작점, 적의 반격 도착점, 카메라, 미니맵 일부가 바닥 기준 상수에 기대고 있다. 모두 같은 월드 좌표 배치를 사용해야 한다.

## D04. 통나무 받침과 낙하

- **Chosen by user**: 기존 통나무 더미의 그림체를 유지하면서 상단을 넓히고 비대칭 나무 받침으로 만든다. 받침은 낮음·중간·높음 3단계다. 어느 높이도 사탕으로 맞힐 수 있는 배치만 허용한다.
- **Chosen by user**: 받침이 쓰러지면 위 몬스터는 받침이 움직인 방향으로 짧은 포물선을 그려 떨어진다. 낙하 도중에는 움직이는 실제 위치에서 사탕에 맞을 수 있다. 착지 후 살아 있으면 새 바닥 위치에서 전투를 계속한다.
- **Chosen by user**: 낙하 높이에 따라 착지 피해 1~3을 준다. 받침 위 몬스터는 해당 통나무의 기존 충돌 피해 3을 중복해서 받지 않는다. 떨어진 몬스터가 다른 몬스터에 닿아도 그 몬스터에게 낙하 충돌 피해를 주지 않는다. 통나무가 다른 적을 실제로 직접 치면 기존 피해 3을 유지한다.
- **Rationale**: 발판 공략이 실제 물리 결과와 연결되면서 같은 대상에 불합리한 중복 피해를 주지 않는다.
- **Implementation constraint inferred from code**: 현재 적의 배치 `y`와 원형 피격 판정은 전투 내내 고정돼 있고, 통나무만 시간별 이동 경로를 가진다. 낙하 적의 경로·피격 판정·착지 후 위치를 한 결과로 기록해 화면 재생과 피해 계산이 일치해야 한다. 제거된 적이 다시 피격되거나 낙하 피해를 받지 않게 한다. 실제 제거한 체력만 기존 점수 규칙에 반영한다.

## D05. 기본 사탕 3종의 능력

- **Chosen by user**: 현재 장전된 기본 사탕의 고유 발사·충돌 효과를 자동 적용한다. 기존 보유 효과는 유지한다. 숲 시범판은 모험가·연금술사·마법사 3종만 새 효과를 만든다. 눈 지역 해금 사탕 2종의 새 효과는 지역 확장 때 설계한다.
- **모험가 사탕**: 첫 바닥 착지 때 한 번 튀어 다시 날아가고, 두 번째 착지 후 기존처럼 구른다. 기존 세 번째 직접 명중마다 점수 +10은 유지한다. 적이나 장애물에 먼저 닿으면 실제 첫 충돌 규칙을 따른다.
- **연금술사 사탕**: 적 또는 장애물과 충돌하면 충돌점 반경 약 180 월드 단위의 작은 물약 파동을 낸다. 범위 안의 살아 있는 적마다 추가 피해 1을 주며 직접 맞은 적도 포함한다. 기존 소모품 사용마다 점수 +10은 유지한다.
- **마법사 구슬**: 원래 큰 구슬은 계속 날아가고 작은 구슬 2개가 다른 각도로 분리된다. 위로 날린 발사는 비행 정점에서, 낮거나 아래로 날린 발사는 이동 거리 약 1/3 지점에서 분리한다. 작은 구슬은 각자의 실제 궤적에서 적에게 피해 1을 준다. 같은 적이 큰 구슬과 작은 구슬 둘에 모두 닿으면 각각 피해를 받는다. 작은 구슬이 장애물에 닿으면 흔들림만 연출하고 쓰러뜨리거나 지역 장애물 효과를 발동하지 않은 채 통과한다. 기존 세 번째 직접 충돌마다 추가 피해 +1은 유지한다.
- **Shared counter rule**: 기존 ‘세 번째 명중’ 누적 횟수에는 큰 사탕의 직접 명중만 포함한다. 물약 파동과 작은 구슬의 피해는 추가 피해이며 누적 횟수를 올리지 않는다.
- **Rationale**: 소모품이 없어도 장전된 사탕에 따라 조준·착지·다중 피격의 차이가 드러난다.

## D06. 소모품 조합과 정보 표시

- **Chosen by user**: 불공은 새 고유 효과와 함께 발동하되 피해 2배는 큰 사탕의 직접 피해에만 적용한다. 파동과 작은 구슬의 고정 피해 1은 두 배가 되지 않는다. 창을 준비한 발사는 관통 판정을 우선해 그 한 발의 새 고유 효과를 대체한다.
- **Implementation constraint inferred from code**: 현재 `MagicCandyCard`는 장전 사탕의 이름·등급·가능 피해 범위·보유 능력을 보여준다. 시범판에는 새 고유 효과와 창에 의한 일시 대체를 정확히 안내해야 하며, 기존에 숨긴 조준 각도·파워의 숫자는 드러내지 않는다. 물약 파동과 작은 구슬은 실제 물리 접촉이 확인된 대상에게만 피해를 주고, 점수에는 실제 제거한 체력만 더한다.

## D07. 관리자 검토 흐름

- **Chosen by user**: 지도 미리보기에 선택한 숲 라운드의 적·쿠키·발사대·통나무 받침을 함께 보여주고, 그 **동일한 배치**로 테스트 플레이한다. ‘새 배치’는 새 무작위 배치를 만들고 ‘같은 배치 다시 시작’은 시드를 유지한다. 개별 물체 드래그 편집은 이번 시범판에 넣지 않는다.
- **Implementation constraint inferred from code**: 지금 지도 미리보기는 라운드 1·고정 시드의 참조 적만 사용하지만 테스트 플레이는 별도 무작위 시드를 사용한다. 두 화면이 동일한 시드·라운드·적 목록과 월드 좌표를 공유하도록 바꿔야 한다. 관리자 전투는 현재 저장소·리더보드 기록을 남기지 않는다.

## D08. 범위와 검증

- **Included**: 로컬 관리자 숲 시범판, 높이별 적·발사대·통나무 배치, 실제 낙하 궤적과 피해, 기본 사탕 3종의 고유 효과, 불공·창 조합, 지도 미리보기와 같은 배치 테스트, 화면 안내.
- **Later**: 눈·도시·혼돈으로의 확장, 해금 사탕 2종의 새 능력, 사용자 게임과 Azure 공개.
- **Checks**: 무작위 배치의 도달성, 시드 재현, 높은 적·떨어지는 적·착지 적의 실제 피격, 피해·점수의 중복 방지, 사탕별 물리 궤적과 아이템 조합, 관리자/사용자 기능 격리, 데스크톱·모바일 화면을 검증한다.
