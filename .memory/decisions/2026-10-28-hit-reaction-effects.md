# Decisions: 피격 반응 이펙트

- Date: 2026-10-28
- Status: Confirmed for the local Forest studio prototype

## D01. 적용 범위
- **Chosen**: 앞서 정한 로컬 관리자 숲 시범판(`run.studioPrototype === 'forest-elevated-v1'`)에 먼저 적용한다. 사용자 게임, 다른 지역, Azure 배포에는 적용하지 않는다.
- **Rationale**: 고저차·사탕 능력도 같은 시범판에만 있으므로 새 피격 연출을 함께 검토할 수 있다.

## D02. 몬스터 피격
- **Chosen**: 실제 양수 피해를 받은 몬스터만 짧게 움찔하고 사탕빛 파편·충격 고리를 보인다. 피해 숫자는 유지한다. 처치된 몬스터는 피격 순간이 보이도록 잠깐 잔상을 남기고 사라진다.
- **Rationale**: 현재 `MonsterGroup`은 숫자만 표시하고 처치 즉시 DOM에서 제거해 마지막 타격이 보이지 않는다. 특수 사탕의 추가 피해도 실제 `lastEvent.hits`만 따른다.

## D03. 쿠키 피격과 방어
- **Chosen**: 실제 피해를 받으면 기존 반동·숫자에 작은 과자 부스러기와 따뜻한 섬광을 더한다. 방어 성공은 푸른 보호막 파동만 보인다. 빗나간 공격과 피해 0에는 피격 파편을 표시하지 않는다.
- **Rationale**: `PlayerCookie`는 이미 `getPlayerPresentation`의 `response.stage === 'impact'`에서 피해·방어를 구분한다. 새 연출도 이 상태를 읽기만 한다.

## D04. 게임 규칙과 접근성
- **Chosen**: 물리 판정·체력·점수·적 턴의 시점은 바꾸지 않는다. 새 효과는 `pointer-events: none`이고 애니메이션 감소 설정에서는 정적 충격 표시로 대체한다. 화면 전체 흔들림은 사용하지 않는다.
- **Rationale**: 카메라·조준 좌표와 충돌 판정을 유지하면서 모바일에서도 대상을 알아볼 수 있어야 한다.

## Existing behavior to preserve
- 몬스터 피해 숫자, 쿠키 반동·숫자·방어막, 적 투사체의 충돌 표시는 이미 있다. 새 요소는 같은 사건에 덧붙이며 중복 피해를 만들지 않는다.
- 몬스터 사망 직후의 표시 부재는 이번 연출에 직접 영향을 주므로 잠깐의 잔상 처리에 포함한다.
