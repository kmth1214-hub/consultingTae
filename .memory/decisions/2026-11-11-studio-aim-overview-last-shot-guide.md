# Decisions: 관리자 조준 전체 보기와 직전 발사 가이드

- Date: 2026-11-11
- Status: Confirmed
- Scope: 로컬 `/__dev/maps` 관리자 테스트 플레이에서 먼저 검토. 일반 게임과 Azure 배포는 이번 적용 대상이 아니다.
- Related: [관리자 맵 2.5D 재구성](./2026-11-02-studio-map-depth-reconstruction.md)

## D01. 조준 중 전장 확인
- **Chosen by user**: 마우스로 새총을 당기는 동안 `V`를 누르고 있으면 전장 전체가 보이고, 떼면 새총 근접 화면으로 돌아온다.
- **Code-derived constraint**: `Space`는 마법사·연금술사 스톤의 비행 중 능력 발동에 사용된다. 조준 원점은 화면 좌표로 저장되므로 카메라 전환이 드래그 거리와 발사 방향을 바꾸면 안 된다.
- **Rationale**: 멀리 있는 적과 장애물의 거리를 확인하되, 근접 조준의 긴장감은 유지한다. 현재 발사의 전체 탄도나 착탄 예측은 추가하지 않는다.

## D02. 직전 발사 기록
- **Chosen by user**: 이전 턴에 실제로 날린 궤적의 앞 80%와 실제 타격·착지 지점을 다음 조준의 가이드로 보여준다.
- **Implementation judgment**: 같은 전투에서 완료된 가장 최근 발사 한 번만 저장한다. 조준 중에만 희미한 선과 구별되는 접촉점 표식을 월드 좌표에 그린다. 다음 발사가 완료되면 교체하고 지역·라운드·배치·테스트 재시작 시 지운다. 몬스터·장애물 접촉, 바닥 첫 착지, 장외 순서로 실제 첫 종점을 기록한다. 특수 능력의 비행 중 경로 변경도 최종 발사 기록을 따른다.
- **Rationale**: 직전 시도에서 배울 수 있지만 현재 조준의 정답은 보이지 않게 한다. 가이드와 피격 판정은 별개이며 몬스터 체력·점수·발사 횟수를 바꾸지 않는다.

## D03. 적용 순서
- **Chosen by user**: 로컬 관리자 테스트 플레이에 먼저 적용한다.
- **Code-derived constraint**: 현재 `.memory/current.md`의 관리자 2.5D 맵 T03을 먼저 마무리하고 다음 별도 계획에서 구현한다. 지도 미리보기는 전투 조작이 없어 적용하지 않는다.
- **Acceptance**: V 키를 누르고 떼는 동안 발사 벡터가 유지된다. 직전 발사의 실제 80% 궤도와 접촉점이 관리자 화면에만 보인다. 현재 발사의 30% 미리보기 및 바람궁수 자동 유도의 미리보기 숨김 규칙은 유지한다.

## 이전 요청과의 관계
- 관리자 2.5D 맵 재구성 T03은 진행 중이다.
- 구조물 안·위·사이 몬스터 배치와 전투 시작 전체 조망 연출 확인은 [별도 아이디어](../ideas/2026-11-02-elevated-structures-and-opening-camera.md)로 남아 있다.
- 보스 세 번째 공격 또는 세 번째 피격 이후의 사탕 직접 조작·회피 장면은 [2차 업데이트 아이디어](../ideas/2026-11-02-boss-third-hit-dodge-transition.md)다. 발동 조건은 별도 결정이 필요하다.
