# Decisions: 관리자 무기 등급과 도시 몬스터 크기

- Date: 2026-10-31
- Status: Confirmed

## D01. 관리자 무기 등급 선택
- **Chosen**: 지도 스튜디오와 테스트 플레이 설정에서 시작 스톤 등급 C·B·A를 선택한다. 관리자 시범전의 전용 스톤 1개와 기본 스톤 2개에 선택 등급을 함께 적용하며 재시작에도 유지한다.
- **Rationale**: 전용 능력의 등급별 효과와 전투 피해를 같은 조건에서 바로 비교할 수 있다. 일반 게임의 보상·합성 규칙은 유지한다.

## D02. 도시 몬스터 추가 확대
- **Chosen**: 기존 관리자 월드 1.5배에 더해 도시 몬스터의 몸체·피격 콜라이더만 1.5배 확대한다. 쿠키·새총·사탕·장애물의 크기는 유지한다. 지도 미리보기와 같은 배치의 테스트 플레이에 적용한다.
- **Rationale**: 기존 관리자 시범판 검토 흐름을 따르고, 보이는 몸체와 실제 충돌 위치를 일치시킨다. 공개 게임·Azure는 이번 검토에서 유지한다.
