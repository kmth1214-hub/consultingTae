# 관리자 지도 테스트 플레이

- 개발 전용 `/__dev/maps`에서 실제 BattleScreen을 재사용해 숲/눈/도시/혼돈의 라운드1~3을 바로 플레이한다. 일반 유저 화면의 라운드 건너뛰기는 추가하지 않는다.
- 지역/라운드/쿠키 선택, 보스 라운드의 다음 공격을 특수 공격으로 설정하는 옵션을 제공한다. 시작 HP100/사탕9/소모품 각3개, 모든 쿠키를 테스트할 수 있다.
- 테스트 중 지역·라운드를 다시 선택하거나 같은 배치 재시작/새 배치/지도 검토로 복귀가 가능하다. 이전 전투를 폐기하고 새 세션으로 시작해 타이머와 상태가 섞이지 않는다.
- core gameSession은 수정하지 않는다. dev 전용 engine.createRunState 어댑터와 메모리 프로필 저장소를 사용한다. 해금/localStorage/리더보드/로그인에 영향을 주지 않는다. 한 전투 종료 시 테스트 결과만 보여준다.
- 프로덕션 DEV gate와 제외 동작을 유지한다. Azure 관리자 인증은 기존 배포 단계에서 연결할 별도 작업이다.
