# Decisions: 관리자 지도 몬스터 가독성

- Date: 2026-10-28
- Status: Confirmed

## D01. 관리자 지도 시작 구도
- **Chosen**: 로컬 지도 스튜디오의 기본 카메라를 2배 확대하고 새총 쪽을 보여준다. 드래그로 먼 지역을 확인하고, `전체 보기` 버튼으로 1배 전체 조망에 돌아간다. Home은 확대된 시작 구도로 돌아간다.
- **Rationale**: 폭 613px 지도 창에서 1.5배 월드 몬스터도 화면상 약 15px에 불과했다. 2배 카메라에서 약 31px로 보인다.

## D02. 관리자 미리보기 체력표
- **Chosen**: 지도 미리보기에서는 일반 몬스터와 보스의 체력 숫자표를 숨긴다. 실제 테스트 플레이의 체력 표시는 유지한다.
- **Rationale**: 미리보기에서 약 23px 체력표가 약 15px 몬스터 그림을 가려 외형을 알아보기 어려웠다.

## D03. 적용 범위
- **Chosen**: 로컬 관리자 지도 화면만 조정한다. 기존 1.5배 월드 물리·충돌, 사용자 게임, Azure 배포판은 유지한다.
- **Rationale**: 문제는 전장 물리보다 전체 맵을 작은 지도 창에 맞추는 미리보기 카메라와 레이블에 있었다.
