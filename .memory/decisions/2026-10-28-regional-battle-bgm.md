# Decisions: Regional Battle BGM

- Date: 2026-10-28
- Status: Confirmed
- Feature: `regional-battle-bgm`

## D01. 제작 범위와 공개 순서

- **Chosen by user**: 숲·눈·도시·혼돈의 전투 BGM 4곡을 한 번에 제작한다. 먼저 로컬 사용자 게임에 연결해 전투·보스전 전환과 음량 조절을 확인한다. Azure 배포는 곡을 검토한 뒤 진행한다.
- **Rationale**: 지역마다 다른 전투 분위기를 바로 비교할 수 있고, 현재 서비스 중인 Azure 게임의 음악은 검토 전까지 바뀌지 않는다.

## D02. 지역별 감정선

- **Chosen by user**: 숲은 다급하게 도망치는 느낌, 눈은 새로운 캐릭터와 조우하는 느낌, 도시는 괴물을 물리치며 용감하게 헤쳐 나가는 느낌, 혼돈은 불규칙하고 혼란스러운 느낌으로 만든다.
- **Rationale**: 같은 전투 조작을 반복해도 지역의 서사와 리듬이 구별되도록 한다.

## D03. 공통 악기 구성

- **Chosen by user**: 동화풍 게임 음악을 공통 스타일로 삼는다. 현악기·목관악기·종소리·타악기 느낌을 중심으로 하고, 혼돈 곡에는 뒤틀린 전자음을 섞는다.
- **Rationale**: 현재 게임의 밝은 판타지 그림체와 맞추면서 혼돈의 이질감을 낸다.

## D04. 보스전과 반복 길이

- **Chosen by user**: 지역당 한 곡을 유지하되, 3라운드 보스전에는 타악기와 속도감을 더해 긴장감을 높인다. 각 곡은 약 60~75초의 자연스러운 반복곡으로 만든다.
- **Rationale**: 네 지역의 음악 정체성을 유지하면서 보스전을 소리로도 구분한다.

## D05. 현재 코드에서 확인한 제약

- **Inferred from code**: React 게임에는 음원 파일, 오디오 재생기, BGM 설정 UI가 없다. 게임 시작은 사용자의 버튼 클릭으로 진행한다. 브라우저가 사전 동의 없는 자동 재생을 막을 수 있으므로 사용자 동작 이후 음악을 시작하고, 음소거·음량 조절을 제공한다.
- **Implementation constraint**: 지역 또는 라운드가 바뀔 때 음악 상태를 게임 상태와 동기화하고, 전투 외 화면에서는 의도치 않게 이전 곡이 계속 재생되지 않게 한다. 브라우저 탭 전환과 오디오 오류에도 게임 진행은 계속 가능해야 한다.
- **Asset constraint**: 프로젝트에 기존 음악 소스나 전용 오디오 생성 도구가 없다. 계획 단계에서 원곡을 만들 수 있는 로컬 제작 방식과 브라우저 재생 형식을 정하고, 사용 권한이 불명확한 외부 음원을 가져오지 않는다.

## D06. 별도 작업과의 관계

- **Previously confirmed**: 실제 사용자 게임의 몬스터가 등간격·동일 높이로 배치되어 단조롭다는 문제는 남아 있다. BGM 작업 이후 플레이 화면의 배치를 개선한다.
- **Outside this decision**: 몬스터 배치, 충돌 판정, Azure 배포, 리더보드 변경은 이번 BGM 작업 범위에 포함하지 않는다.
