# Decisions: Slot Machine Reel Motion

- Date: 2026-10-30
- Status: Confirmed

## D01. 슬롯 화면 구성
- **Chosen**: 가로로 긴 동화풍 금빛·나무 기계 안에 세 개의 세로 릴을 배치한다. 각 릴에 세 칸이 보여 기존 3×3 판정을 그대로 읽을 수 있게 한다.
- **Rationale**: 사용자가 제공한 `slotmuchine.mp4`의 실제 회전감과 가로형 구도를 참고하되 게임의 기존 동화풍 색감과 어울리게 한다. 참고 영상 자체는 게임 자산으로 복사하거나 배포하지 않는다.

## D02. 시작 조작
- **Chosen**: 기계 오른쪽 손잡이를 클릭하거나 터치하면 손잡이가 내려가는 모션 뒤 릴이 회전한다. 손잡이는 접근 가능한 버튼으로 만든다.
- **Rationale**: 사용자가 손잡이 클릭 방식을 선택했다. 키보드 사용자는 같은 버튼을 Enter·Space로 조작할 수 있다.

## D03. 회전과 결과 공개
- **Chosen**: 총 약 2.5초 동안 세 릴이 회전하고 왼쪽부터 순서대로 멈춘다. 마지막 릴이 멈출 때 당첨선과 보상 문구를 보여준다. 회전 중 중복 입력과 다음 화면 이동을 막는다.
- **Rationale**: 영상의 움직임을 느낄 수 있으면서 반복 보상 화면이 길어지지 않는 속도로 사용자가 선택했다. 모션 감소 설정에서는 회전을 생략하고 결과를 즉시 보여준다.

## D04. 보상 규칙
- **Chosen**: 3×3의 가로 3줄과 대각선 2줄, 네 종류의 스톤 기호 및 기존 소모품 슬롯의 당첨·실패 규칙을 유지한다. 보상 확률과 지급 개수는 바꾸지 않는다.
- **Rationale**: 요청은 슬롯머신의 시각과 조작 개선이다. 현재 `assets/js/battle-engine.js::spinRewardSlot`의 결과가 게임의 소유 스톤·소모품 상태와 연결돼 있다.

## D05. 배포 시점
- **Chosen**: 슬롯 수정은 로컬에서 먼저 검증한다. 다음 본 서버 배포에는 BGM도 포함한다.
- **Rationale**: 사용자가 BGM을 다음 배포에 포함하기로 했다. 현재 GitHub 배포 workflow의 `VITE_ENABLE_BGM=false`는 배포 시점에 함께 변경한다.

## Existing constraints
- `SlotMachine.jsx`는 라운드, 야영지, 혼돈 소모품 보상에서 공유된다. 세 화면 모두 같은 레버와 릴 동작을 사용한다.
- `spinRewardSlot`은 호출 즉시 보상을 지급한다. 화면에서는 회전이 끝날 때까지 결과를 가리고 계속 버튼을 잠가야 한다.
- `.memory/current.md`의 이전 T06은 Azure 리더보드의 구 `GLOBAL` 기록 초기화가 끝나지 않아 미완료 상태다. 이 슬롯 변경은 별도 작업으로 기록하고 해당 잔여 사항을 완료로 표시하지 않는다.
