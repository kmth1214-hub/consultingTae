# 착지 후 굴림 표시 보완

- 사용자 관찰: 발사 후 사탕이 굴러가는 모션을 인지하기 어렵다.
- 재현: 숲 seed4927, angle=-5°, power=.6. 실제 굴림 거리50.18, 표시90.32ms. 브라우저 고정 시계에서 굴림6프레임으로 실패.
- 물리 거리(최대 지름5배)·마찰·피해·충돌은 유지하고 presentation clock에서 지면 구간만 약240~440ms 이상 표시한다.
- 비행/통나무/접촉 이벤트도 동일한 simulationTime으로 구동하며 전투 처리는 기존 완료 콜백에서1회 수행한다.
- 회전은 이동 방향과 지름에 맞추고 먼지 위치용 transform과 CSS 애니메이션용 transform을 서로 다른 SVG 그룹에 둔다. 착지 그림자로 지면 접촉을 보강한다.
- 모션 감소 모드는 기존80ms 처리와 회전/먼지 생략을 유지한다.
