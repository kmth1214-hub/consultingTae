# Decision: 실제 궤적의 관통 사탕

- 사용자 요청: 창 사용 즉시 적이 피해를 받는 버그 수정. 다음 사탕을 직접 던지고 실제로 관통해 닿은 적만 피해. 창/불공은 장전과 비행 모습도 변경.
- 기존 창 수치 유지: 첫 피해2~5, 이후 닿은 대상마다1 감소, 최대3마리. 적이 살아도 관통. 궤적 밖 적/닿지 않은 후속 적은 피해 없음.
- 선택은 준비만 수행(수량1 차감/기존 연금술사 사용점수). 피해 RNG/탄약/적 공격은 실제 발사 때. 취소·dead zone은 준비 유지, 수락한 빗나간 발사는 소모.
- 기존 창은 영구 사탕 명중 능력을 발동하지 않았으므로 유지. 바람 유도 없이 실제 수동 궤적 사용. 장애물·굴림·연쇄는 실제 통과 경로에 따라 기존 처리와 통합.
- 불공은 기존 다음 사탕2배 규칙 유지. 별도 새 스펙/등급/확률 변경 없음.
- 진단 재현: 단독 engine.useConsumable(spear)만으로 snow5마리 HP [4,4,4,4,4]→[0,1,2,4,4]. UI/애니메이션 없이 재현하므로 useConsumable의 getLivingEnemies.slice(0,3) 직접 피해가 원인. 기존 stacked path도 첫 적에서 멈추므로 준비 플래그만으로는 해결되지 않음.
