# Decisions: 일반 게임 숲 몬스터 고저차 배치

- Date: 2026-10-29
- Status: Confirmed from the prior forest-first design and the request to improve the public game before deployment. A later explicit all-region choice supersedes this scope.

## D01. 이번 공개 범위

- 이전에 확정한 숲 우선 순서를 따른다. 일반 게임의 숲 2라운드에 통나무 받침 위 일반 몬스터 1마리를 보장한다. 숲 1라운드는 바닥 적으로 조작을 익히고 3라운드 보스는 바닥에 둔다.
- 눈·도시·혼돈의 높이 배치와 받침 피해 규칙은 별도 확장이다. 이번 변경을 검증한 뒤 음악을 제외하고 배포한다.
- 지역마다 각 라운드의 배치 시드가 바뀌며 같은 라운드 안에서는 배치가 고정된다.

## D02. 물리와 연출

- 관리자 숲 시범판에서 검증한 `forest-elevated-v1`의 높이별 통나무 받침, 쓰러질 때의 낙하 궤적, 1~3 착지 피해, 생존 시 바닥 이동을 사용자 전투의 실제 좌표와 판정에 연결한다.
- 라운드 2부터 새총과 쿠키가 함께 낮은 발판에 서거나 바닥에 서는 기존 시범 규칙을 재사용한다. 보스의 발판은 쓰러지지 않는다.
- 발사 전 미리보기, 실제 발사, 반격, 미니맵이 동일한 배치와 착지 결과를 읽어야 한다.

## D03. 기능 경계

- 이번 사용자의 요청은 **몬스터 배치**다. 관리자 시범판에 묶여 있는 모험가 튀기기·연금술사 파동·마법사 분리 구슬과 1.5배 크기, 지역 융합 몬스터는 일반 게임에 아직 공개하지 않는다.
- 레이아웃·낙하 판정 활성화와 사탕 능력 활성화를 별도 상태 필드로 분리한다. 기존 소모품과 지역 장애물 효과는 유지한다.
- Azure용 BGM 비활성 설정은 앞선 배포 게이트를 그대로 사용한다.

## D04. 검증 기준

- 숲 2라운드에서 받침과 적은 겹쳐 보이되, 다른 적·장애물과 잘못 겹치지 않고 모두 실제 조준으로 도달 가능해야 한다.
- 받침 충돌 시 위 적의 낙하 피해는 한 번만 적용하고, 점수·적 반격·라운드 전환이 중복되지 않는다.
- 숲 외 지역의 기존 배치와 관리자 시범판 설정은 유지한다.
