# Decisions: 마법사 스톤 직접 명중 후 자동 분열

- Date: 2026-11-11
- Status: Confirmed

## D01. 발동 시점

- **Chosen by user**: 특수 능력을 직접 누르기 전에 큰 마법사 스톤이 몬스터에게 닿으면, 그 명중 직후 자동으로 분열한다.
- **Code finding**: `preparePhysicalFlight`와 `BattleArena`에는 이미 명중 시각의 `auto-contact` 호출이 있다. 다만 자식 구슬이 명중 지점에서 곧바로 같은 몬스터에 다시 충돌할 수 있어 발동 장면이 거의 보이지 않는다.
- **Implementation**: 수동 클릭·Space, 장애물 접촉, 착지 후 자동 발동 규칙을 유지한다. 직접 명중이 자동 발동을 일으킨 경우 큰 스톤의 선행 충돌을 분명히 보여 준 뒤 분열을 표시한다.

## D02. 직접 명중 뒤 자식 구슬 대상

- **Chosen by user**: 자동 분열할 때 작은 구슬은 이미 직접 맞은 몬스터를 지나 발사 방향의 뒤쪽 적에게 날아간다. 뒤쪽 적이 없으면 구슬은 그대로 비행한다.
- **Implementation**: 이 제한은 `auto-contact` 직접 명중 뒤의 분열에 적용한다. 작은 구슬이 뒤쪽 적에게 실제로 닿으면 각각 기존 피해 1을 준다. 수동 발동의 기존 타격 규칙은 유지한다.
- **Rationale**: 큰 스톤과 작은 구슬이 같은 자리에서 즉시 연속 충돌하는 현상을 줄이고 분열 경로를 읽을 수 있게 한다.

## D03. 검증 범위

- 로컬에서는 직접 명중 자동 발동의 국소 테스트와 빌드만 수행한다. 전체 테스트는 배포 시 실행한다.
- 이번 요청은 일반 게임 규칙에 적용하고, Azure 배포는 별도 요청 때 진행한다.
