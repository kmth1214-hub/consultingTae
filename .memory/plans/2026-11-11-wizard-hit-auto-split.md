# Plan: 마법사 스톤 직접 명중 후 자동 분열

## Goal

마법사 스톤이 수동 발동 전에 몬스터를 직접 맞혔을 때 명중 후 자동 분열을 확인할 수 있게 한다. 작은 구슬은 직접 맞힌 적을 지나 발사 방향 뒤쪽의 적만 실제 충돌로 공격한다.

## Decision

- [확정 결정](../decisions/2026-11-11-wizard-hit-auto-split.md)
- 사용자는 자동 발동 시점을 요청했다. 기존 코드는 이미 명중 시 자동 호출하지만 이펙트와 자식 비행이 짧아 인지하기 어렵다.
- 직접 명중 자동 분열의 자식 구슬은 이미 맞힌 적을 다시 치지 않는다. 수동 발동의 기존 판정은 유지한다. 로컬은 국소 검증만 하고 전체 테스트는 배포 때 진행한다.
