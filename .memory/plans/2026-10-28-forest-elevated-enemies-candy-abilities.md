# Plan: 숲 고저차 몬스터와 기본 사탕 능력 관리자 시범판

## Goal

로컬 `/__dev/maps`에서 숲 1~3라운드의 고저차 전장을 실제 전투 규칙으로 검토한다. 2라운드에는 쓰러질 수 있는 통나무 위의 일반 몬스터 1마리를 보장하고, 낙하 중 실제 위치·착지 피해를 판정한다. 모험가·연금술사·마법사의 현재 장전 사탕에 서로 다른 비행·충돌 능력을 적용하고, 지도 미리보기와 테스트 플레이가 같은 배치·판정을 공유한다.

## Decision

[확정된 결정](../decisions/2026-10-28-forest-elevated-enemies-candy-abilities.md)을 따른다. 이번 계획의 결과는 **개발 서버의 관리자 시범판**에만 나타난다. 일반 사용자 게임과 Azure 배포의 숲 전투 규칙을 바꾸거나 배포하지 않는다.

## Architecture and boundaries

- 정규 월드 좌표는 `src/game/battlefieldModel.js`의 `BATTLEFIELD`(3600×1200, 바닥 y=900)를 유지한다. 높이·충돌·카메라·미니맵이 동일한 좌표를 읽는다.
- 개발 전용 시나리오 표식은 `src/dev/createStudioSession.js`가 만든 run에만 넣는다. 물리 계획과 엔진은 이 표식이 있는 숲 라운드에만 새 규칙을 적용하고, 다른 지역 및 일반 플레이는 기존 경로를 유지한다.
- `preparePhysicalFlight`에서 계산한 단일 궤적·접촉 타임라인이 재생, 판정, 점수의 원본이다. `gameSession`은 예약된 `shotId`와 `encounterId`로만 물리 결과를 커밋한다. 화면 애니메이션은 체력을 따로 변경하지 않는다.
- 높이별 받침과 발사대 발판은 기존 숲 그림체를 확장한 코드 기반 SVG·CSS로 표현한다. 발사대 발판은 고정 지형이고 적 받침만 넘어질 수 있다.
- 사용자 게임·Azure 승격은 이 시범판의 검토 후 별도 작업이다. 해금 사탕 2종의 새 능력, 다른 지역 고저차, 수동 배치 편집도 이번 범위가 아니다.

## Completion criteria

- 같은 지역·라운드·몬스터 목록·seed의 배치와 전투 결과가 재실행 때 동일하다. 새 배치는 새 seed로 바뀐다.
- 숲 2라운드의 정확히 한 일반 몬스터가 통나무 위에 서고, 실제 충돌에 따라 떨어지며 1~3 피해를 받는다. 적과 장애물 겹침·낙하 피해 중복·사망 후 재피격이 없다.
- 모험가 바운스, 연금술사 반경 180 파동, 마법사 2구슬 분기가 실제 충돌과 점수에 일치한다. 불공·창 우선순위와 기존 상시 효과가 유지된다.
- 관리자 지도에서 보이는 배치가 같은 seed로 시작한 테스트 전투와 일치하며, 일반 플레이와 프로덕션 번들에는 새 규칙이 나오지 않는다.
- 관련 단위 테스트, 관리자 E2E, 전체 `npm.cmd test`, `npm.cmd run build`가 통과한다.

## Known regression traps

- 기존 `witnessAt`은 시작점 (284, 812)을 상수로 사용한다. 발사대를 올리면 이 값 때문에 불가능한 배치를 통과시키거나 가능한 배치를 버릴 수 있다.
- 현재 숲 통나무는 정적 `enemy.collider`를 검사하고 `logHit` 대상에 즉시 3 피해를 준다. 받침 위 몬스터를 그 검사에서 제외하고 낙하 타임라인을 따로 연결해야 한다.
- 엔진은 일반탄의 `hitIds`를 한 대상만 남기고, 현재 타임라인의 `directHitTime`은 단일 사탕 기준이다. 분기 구슬·파동은 검증된 별도 접촉으로만 추가한다.
- `MapStudio` 미리보기는 지금 1라운드 참조 뱀과 별도 seed를 쓰며, `StudioPlay` 재시작 버튼도 seed를 새로 뽑을 수 있다. 미리보기용 배치와 테스트 전투의 seed·적 목록을 한 곳에서 생성해야 한다.
- 낙하·분기·파동 재생 완료보다 먼저 `fireShot`을 커밋하면 적 반격 또는 라운드 종료가 일찍 나올 수 있다. 물리 시뮬레이션 완료 시간을 함께 전파한다.
