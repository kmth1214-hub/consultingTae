## Execution notes
- T01 전투 모델·세션·배치는 같은 전환 계약에 의존하므로 함께 구현한다. T02는 이미 확정한 이벤트만 재생한다. T03에서 관리자와 기존 전체 흐름의 호환성을 검증한다.
- 기존 미커밋 작업 7건과 사용자 목업 변경을 보존한다. 자동 승인 검토 제한이 계속되면 커밋을 우회하지 않고 Task별 검증 결과·커밋 메시지와 대기 상태를 기록하며 사용자가 요청한 구현 순서는 계속 진행한다. 검증 완료와 커밋 완료를 구분한다.
- 범위 밖: 1인칭 기믹, 날씨, 궤도 뒤틀림, Azure 배포. 인접 기능을 임의로 확대하지 않는다.
