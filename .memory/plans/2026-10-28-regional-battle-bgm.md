# Plan: 지역별 전투 BGM

## Goal
숲·눈·도시·혼돈의 원곡 4개를 60~75초 반복 음악으로 만들고, 각 지역 3라운드에서 같은 곡의 보스 변주를 들려준다. 로컬 사용자 게임과 개발 지도 테스트 플레이에서 재생·음량·음소거를 확인한다. Azure 배포는 하지 않는다.

## Sequence
T01 악보·합성·재생 엔진 → T02 사용자 게임·관리자 테스트 전투 연결과 조절 UI. 각 Task는 독립 검증 후 한국어 커밋한다.

## Constraints
- 외부 저작권 음원이나 추가 서비스 의존성 없이 Web Audio로 원곡을 합성한다. 현악·목관·종·타악은 합성 음색으로 표현하므로 실제 악기 녹음과 질감은 다르다.
- 사용자 조작 전 브라우저 자동 재생을 강요하지 않는다. 음악 오류가 전투를 중단하지 않게 한다.
- 실제 사용자 게임의 몬스터 배치 문제와 Azure 배포는 별도 작업이다.
